# Fysisk-nettverk

Jeg koblet Fysisk nettverk , og gjørt IP- konfigurasjon og tilkoblinstest.Etter konfiguret og testing av fildeling .Med Porter og Nmap kontrollere nettverksforbindelsen mellom CLIENT01 og SERVER01 . Den kjørte Wireshark og fant Source IP, destination IP,request and reply.forklare forskjellen mellom  Nmao og Wireshark. Gjørte en Fysisk feilsøkning. jeg lagte et nettverksdiagram i Cisco Packet Tracer . Hovedkontoret og salg-nettverket kan kommunisere med hverandre. Konfigurer DHCP  og DNS på SERVER01 . Jeg brukte simulation mode for å undersøke kommunikasjonen mellom to klienter i samme LAN. Derreter testet Telnet - tilkoblingen.
